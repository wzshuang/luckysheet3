# Luckysheet3

Vue 3 + TypeScript rewrite of Luckysheet (Path A MVP).

## Packages

- `@luckysheet3/core` — framework-agnostic workbook engine (Canvas, commands, formulas)
- `@luckysheet3/vue` — `<LuckySheet>` component & composables
- `@luckysheet3/compat` — optional `create` / `getCellValue` / `setCellValue`
- `@luckysheet3/playground` — demo app

## Develop

```bash
pnpm install
pnpm test
pnpm dev
```

Open http://localhost:5173
